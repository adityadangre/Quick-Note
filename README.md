# Quick Note

Quick Note is a simple and user-friendly note-taking application built with React Native and Expo. It allows users to create, edit, delete, search, and share notes while storing all data locally using AsyncStorage. The app is designed to provide a fast and lightweight note management experience without requiring an internet connection or user account.

## Features

### Personalized Experience
- Enter your name on first launch
- Personalized greeting based on the time of day
- User information stored locally using AsyncStorage

### Note Management
- Create new notes with a title and description
- View detailed note information
- Edit existing notes
- Delete notes with confirmation prompts
- Automatically track creation and update timestamps

### Search Notes
- Real-time note searching
- Instant filtering based on note titles
- Clear search functionality

### Share Notes
- Share notes using the device's native sharing options
- Easily send notes to messaging, email, or social media apps

### Local Data Persistence
- Notes are stored locally using AsyncStorage
- Data remains available even after closing the application
- No internet connection required

## Installation

### Prerequisites

- Node.js
- npm
- Expo CLI

### Clone the Repository

```bash
git clone <repository-url>
cd Quick-Note
```

### Install Dependencies

```bash
npm install
```

### Run the Application

```bash
npm start
```

or

```bash
expo start
```

### Run on Device

- Install the Expo Go app on your Android or iOS device.
- Scan the QR code generated by Expo.
- The application will launch on your device.

## How It Works

1. Enter your name when launching the app for the first time.
2. Create notes using the add button.
3. Store notes locally using AsyncStorage.
4. Search notes instantly using the search bar.
5. Open any note to view details.
6. Edit, delete, or share notes as needed.
7. Access your notes anytime without an internet connection.
